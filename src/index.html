If loading takes too long, please hard refresh your browser.

Chrome: Hold the ⇧ Shift key and press the F5 key.
Microsoft Edge: Hold the Ctrl key and press the F5 key.
Internet Explorer: Hold the Ctrl key and press the F5 key.
Firefox: Hold both the Ctrl and ⇧ Shift keys and then press R .


*Note: some old versions of these browsers are not compatible with the system.
We recommend to use other browsers for accessing MyPortal.

If you're using browsers on your mobile, terminate the browser and try accessing MyPortal again.
